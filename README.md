# Student Expense Calculator

A simple, lightweight application designed to help students track their income, manage daily expenses, and stay within their monthly academic budget.

## Features

* **Expense Logging:** Track spending with descriptions, categories, and timestamps.
* **Smart Categorization:** Group expenses into student-specific categories like Food, Books, Rent, and Transport.
* **Budget Tracking:** Input monthly allowances or income to instantly see remaining balances.
* **Data Summary:** View clear totals to evaluate spending habits over time.

## Tech Stack

* **Frontend:** HTML5, CSS3
* **Scripting:** Java / JavaScript

## Getting Started

Follow these steps to set up and run the application locally.

### Prerequisites

Ensure you have a modern web browser installed (for the web-based UI) or the Java Development Kit (JDK) configured if running the core logic as a local terminal program.



### Running the Application

* **For the Web UI:** Open the `index.html` file directly in any browser.
